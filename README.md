# Shopping List

## Ссылка на рабочую версию
https://mgtsuu.github.io/Shopping-list/

## Описание проекта

Shopping List — Сайт для создания списка покупок.
Пользователь может добавлять товары, удалять их и отмечать уже купленные.

## Функциональность

- Добавление товаров
- Удаление товаров
- Отметка купленных товаров
- Подсчёт оставшихся покупок
- Очистка всего списка
- Сохранение данных через localStorage

## Использованные технологии

- HTML
- CSS
- JavaScript
- DOM API
- localStorage

## Как запустить проект локально

1. Скачать проект.
2. Открыть папку в Visual Studio Code.
3. Установить Live Server из каталога расширений Visual Studio Code
4. Запустить index.html через Live Server.
5. Сайт откроется в браузере.
